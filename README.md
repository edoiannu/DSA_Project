# Data Structures & Algorithms Course Project

**Academic Year:** 2025/2026

## Overview

This repository contains implementations and explorations of data structures and algorithms as part of a coursework project. The project combines multiple programming languages including Python, JavaScript, Cython, and C to demonstrate different approaches and optimizations for algorithmic problems.

## Project Structure

- **`hamming.ipynb`** - Jupyter notebook containing Hamming code implementations and analysis
- **`Alice.txt`** and **`Bob.txt`** - Sample data files for algorithm demonstrations
- **`my-venv/`** - Python virtual environment directory (contains dependencies)

## Getting Started

### Prerequisites

- Python 3.8+
- Node.js (for JavaScript components)
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/edoiannu/DSA_Project.git
   cd DSA_Project
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv my-venv
   source my-venv/bin/activate  # On Windows: my-venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

### Running Notebooks

Open the Hamming code notebook:
```bash
jupyter notebook hamming.ipynb
```

### Running Python Scripts

Execute any Python implementations directly:
```bash
python script_name.py
```
